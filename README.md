## 実データ同期
GitHub Actions → `Sync BOAT RACE data` → `Run workflow`。
同期すると `data/today.json` と `data/YYYY-MM-DD.json` が生成される。

公式の番組表LZHは実選手・締切へ、競走成績LZHは着順・払戻へ変換する。1レースずつ公式HTMLを巡回しない。

## まだ「別ルート」のもの
リアルタイムオッズ自動同期。現時点では公式オッズページを開き、必要ならアプリ内に倍率を任意入力する。最終精算は確定払戻を使うため、仮想収支自体は実結果で確定する。

## 個人利用の実機確認手順
1. 全ファイルをGitHubリポジトリへ配置
2. Actionsで当日の同期を1回実行
3. PagesをiPhone Safariで開く
4. 開催場 → レース → 実選手6名を確認
5. 仮想投票
6. レース後にもう一度Actions同期
7. 記録画面で実結果・仮想払戻を確認
