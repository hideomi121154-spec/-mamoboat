# まもボート PERSONAL v3.1

実際のBOAT RACEに、換金・購入・譲渡できない仮想メダルだけで参加する個人用Webアプリです。現金舟券の代わりに使い、現金を使わずに済んだ金額、衝動、追い上げ、短時間連投などを端末内へ記録します。

BOAT RACE公式のサービスではありません。公式ロゴ・公式画面・現金投票・入出金機能は使用しません。

## v3.1で完成している流れ

1. 公式公開の番組表日次LZHから、当日開催場・各場1〜12R・各レース6艇・登番・選手名・締切予定時刻を取得
2. 単勝、複勝、2連単、2連複、拡連複、3連単、3連複を、通常・BOX・フォーメーションで仮想投票
3. 締切済レースを灰色表示し、受付中・締切済・結果確定と残り時間を表示
4. 選手名から公式レーサープロフィール、舟券種から対応する公式オッズ、各レースから公式結果を別画面で確認
5. 公式公開の競走成績日次LZHから、実着順と7舟券種の確定払戻を取得して自動精算
6. レース後に現金購入の有無と衝動を記録し、「守った現金」を集計
7. 低自信×高衝動、取り返したい参加、外れ後の追い上げ、短時間の金額増加・連投を分析

## 負荷・権利への配慮

安全側に倒した運用を標準にしています。

- 自動取得対象は、公式がダウンロード用として公開している番組表・競走成績LZHだけです。
- GitHub Actionsは毎時実行、ダウンロードは1並列です。データが変わらなければコミットしません。
- オッズ画面、個別結果画面、レーサープロフィールは自動巡回・複製・再配信しません。利用者がリンクを押した場合だけ公式サイトを開きます。
- オッズはアプリへ自動転載せず、必要なら公式画面を見て任意入力します。仮想精算は公式日次成績の確定払戻を使います。
- 公式ロゴ、公式サイトの画像・CSS・画面レイアウトは使用しません。艇番の1〜6号艇色など、投票に必要な一般的な表示規則だけを使い、まもボート独自の配色・構成にしています。
- 公式サイトの公開条件やサイトポリシーが変わった場合は、同期運用を見直してください。

公式の公開データ案内: <https://www.boatrace.jp/owpc/pc/extra/data/download.html>

## 会場振り分け

日次B/Kファイルは複数場を連結したファイルです。会場名を1回だけ推定せず、公式ファイル内の制御行を場境界として扱います。

- 番組表: `NNBBGN` から `NNBEND`
- 競走成績: `NNKBGN` から `NNKEND`
- `NN` は01〜24の場コード
- 「ボートレース○○」見出しは、制御行欠損時の補助判定だけに使用

生成前に、開催場ごとに12R、各Rに1〜6号艇、4桁の登番、氏名、締切時刻が揃っているかを検証します。不完全なら処理を失敗させ、既存JSONは原子的書き込みにより維持します。蒲郡（07）・常滑（08）を含む全国24場へ対応しています。

## データ更新と結果の遅延

`Sync BOAT RACE data` が次を生成します。

- `data/today.json`: JST当日の検証済みデータ
- `data/YYYY-MM-DD.json`: 日付をまたいだ未精算用の履歴データ

通常同期はJST 06:15〜23:15に毎時、前日成績の最終確認はJST 00:35と05:35に実行します。アプリはGitHub Pages上のJSONだけを5分ごとに確認します。この確認はBOAT RACE公式サイトへのアクセスではありません。

日次競走成績はレース直後ではなく、場単位または公開タイミングにより遅れて反映されます。直後の結果はレース画面・記録画面の「公式結果」で確認でき、仮想精算は日次成績が公開された後に自動で行われます。

## データ保管

行動記録はブラウザの `localStorage` だけに保存され、外部サーバーへ送信しません。設定画面からJSONを書き出せます。週の仮想メダルは月曜に10,000Cへリセットします。PWAはデータJSONを常に再確認し、通信失敗時だけ直前キャッシュへフォールバックします。
